04Applied machine learning project

Explainable AI-Powered Fraud Detection

Problem
Only 492 of 284,807 transactions were labelled as fraud, so a model could appear highly accurate while missing the cases that mattered.
What I built
I built a reproducible fraud-detection pipeline that compared three classifiers, selected an alert threshold using validation data, evaluated operational metrics, explained model behaviour, and documented its limitations.
What I learned
Accuracy is misleading for rare events. Model thresholds should reflect false positives, investigation workload, and the real cost of missed cases.
Result
On the untouched test set, the selected model achieved 95.7% precision, 69.5% recall, 0.805 F1, and 0.965 ROC-AUC. It escalated 69 of 56,746 transactions, including 66 confirmed fraud cases and 3 false positives.
